# Todo Vue

Todo Vue — небольшое одностраничное приложение для ведения списка задач. Проект собран на Vue 3 и Vite, использует Vue Router для маршрутизации и Pinia для хранения пользовательских данных.

## Возможности

- Просмотр стартового списка задач.
- Добавление новой задачи по кнопке `+` или клавише `Enter`.
- Отметка задачи выполненной кликом по названию.
- Удаление задачи кликом по иконке закрытия.
- Редактируемый заголовок списка.
- Подключённые локальные шрифты и базовая адаптивная сетка интерфейса.

## Стек

- [Vue 3](https://vuejs.org/) — UI-фреймворк.
- [Vite](https://vitejs.dev/) — dev-сервер и сборка.
- [Vue Router](https://router.vuejs.org/) — маршрутизация.
- [Pinia](https://pinia.vuejs.org/) — хранилище состояния.
- [Vitest](https://vitest.dev/) — запуск тестов.
- ESLint и Stylelint — проверки качества кода.

## Требования

- Node.js 16 или новее.
- npm 8 или новее.

## Установка

```bash
npm install
```

## Переменные окружения

Для запроса пользовательских данных клиент использует переменную `VITE_BACK` как базовый URL API:

```env
VITE_BACK=http://localhost:3000
```

Если API не используется, переменную можно не задавать: основной список задач работает локально в памяти браузера.

## Запуск в режиме разработки

```bash
npm run dev
```

По умолчанию Vite поднимет dev-сервер и выведет локальный адрес в терминал.

## Сборка

```bash
npm run build
```

Готовые статические файлы будут созданы в директории `dist`.

## Предпросмотр production-сборки

```bash
npm run preview
```

## Проверки и тесты

```bash
npm run lint
npm run test
npm run coverage
```

> Скрипт `lint` запускает JavaScript/Vue linting. CSS linting в `package.json` оставлен закомментированным в составе команды.

## Структура проекта

```text
src/
├── api/              # HTTP-клиенты
├── assets/           # Шрифты и иконки
├── components/       # Переиспользуемые Vue-компоненты
├── router/           # Конфигурация маршрутов
├── stores/           # Pinia-хранилища
├── views/            # Страницы приложения
├── App.vue           # Корневой компонент
└── main.js           # Точка входа
```

## Основные маршруты

- `/` — список задач.
- `/:item` — маршрут для отображения компонента задачи.

## Полезные команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запустить dev-сервер. |
| `npm run build` | Собрать production-версию. |
| `npm run preview` | Предпросмотреть production-сборку. |
| `npm run lint` | Запустить ESLint с автоисправлением. |
| `npm run test` | Запустить тесты через Vitest. |
| `npm run coverage` | Сформировать отчёт покрытия тестами. |
